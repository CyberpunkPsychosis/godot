# 超级外卖员(原型)

头顶外卖塔一路配送:货越叠越高越晃,跳路障、钻矮桥、躲汽车,把单送到街尾的客户手里。

## 怎么玩

1. 用 Godot 4.4 打开这个文件夹(项目管理器 → 导入 → 选中 `project.godot`)
2. F5 运行。**A/D** 移动,**空格** 跳,**R** 重开
3. 核心体验:去餐厅碰货自动叠上头,注意——
   - 急加速急停塔会甩,倾斜过头整塔散落(散落的能捡回,**奶茶洒了就没了**)
   - 矮桥会刮掉太高的货:先把塔拆散(故意晃倒)再过,或者少叠点
   - 过马路段有车定时冲过来,跳起来躲
4. 送到蓝色客户楼拿小费,货越多小费越高

## 怎么继续做下去(用 AI 控制台)

给这个项目注入 AI 插件(开始菜单 "Add AI Console to a Project" 选中本文件夹),然后在面板里迭代,例如:

> 给倒塔加个屏幕轻微震动和粒子效果
> 加第二关:雨天,地面滑,加速度翻倍
> 加一个计时器,超时小费减半
> 把叠货音效做成音阶,每叠一件音调升高

## 设计核心(给未来的你)

- `stack.gd` 是心脏:**假物理**跟随塔(阻尼摆驱动摇摆,永不炸),倒塔瞬间才切真刚体散落
- 所有视觉都是代码生成的 ColorRect(自带小表情),随时可以换成 Aseprite 画的精灵
- 平衡参数都在 `stack.gd` 顶部几个常数里:摇摆增益 / 弹簧 / 阻尼 / 倾角上限
